# AGENTS.md — docs/legacy

Este directorio es archivo histórico. **No es documentación vigente.**

- No leas un plan completo si no es necesario. Empieza por `**Resumen:**` y por
  `**Secciones:**` del encabezado.
- Si necesitas detalle, busca el encabezado de la sección con
  `rg -n "^## " archivo.md` y lee solo ese rango.
- No uses estos documentos para decidir el estado actual; consulta
  `docs/phases.md` y el código.
- Al archivar un plan nuevo, agrega resumen, estado, fecha y mapa de secciones.
- Mantén actualizado `docs/legacy/README.md` con una línea por documento.
